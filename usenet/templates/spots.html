Spotnet

Spotnet is a decentralised index that lives on usenet: a human “spots” an upload and posts a signed description to {{.Group}}, and every client builds its own copy by reading that group. A spotted release is described by a person rather than inferred from a subject line. We read it; we do not post to it.

Header + document parser ready XOVER listing fields and the repeated X-Xml document.
Signature verification ready Pinned against live spots. A spot signs its message-id, so a valid signature identifies the poster and covers none of the payload — not the title, size or NZB pointer.
Index (headers) {{if .Indexing}}indexing {{else}}off{{end}} Reads {{.Group}} forward, then backfills its history. One round trip per thousand articles, so the whole archive is reachable rather than theoretical.
Fetch (documents) {{if .FetchWired}}running {{else}}not built{{end}} {{if not .FetchWired}}The expensive half: one article fetch per spot for the title, description and NZB pointer, then the NZB itself from alt.binaries.ftd. Until it exists nothing writes origin='spot', so the browse filter and the Spot badge are live but match nothing.{{end}}
