Newsgroups

Only active groups are crawled. Fetch group list asks the primary provider for its complete newsgroup catalog (NNTP LIST — often tens of thousands of names) and adds any that are new, all disabled; nothing you have configured is touched. Then search for the groups you want, enable them, and clear the rest with Remove all inactive groups. A fresh install starts with a curated anime set, so fetching is only needed to index beyond it.
