Before you submit

Search first
Start typing a title and we'll show anything similar. Voting on an existing request counts for more than a duplicate.
One idea per request
A list of ten cannot be given a status or voted on. Separate requests each get tracked.
Say why, not just what
What you were trying to do when you wanted it is usually the most useful part.
Votes set the order
What gets built next is largely what has the most votes, so vote on anything you'd use.
