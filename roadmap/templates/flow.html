Feature Requests board

Sketch out an idea by adding nodes around the existing site flow. Connect related ideas with edges, leave comments, and a mod can promote a good one into the canonical pipeline.

  • + Node / N — add a stand-alone idea node at canvas center.
  • + Mockup — add a UI mockup node. Edit its HTML in the inspector and the canvas thumbnail updates live; users can connect mockups to flow nodes via ports (e.g. "this Login click goes to that mockup").
  • Click a node — inspector opens with all actions.
  • ✏️ Propose change — fork any canonical node to suggest edits (label, description, ports). The amber copy shows up next to the original; edit it, vote on it, mods merge accepted ones back.
  • 👍 Vote — every signed-in user gets one vote per node. Votes drive what mods promote.
  • 🔗 Connect to another node… — pick a port on the source, then click the target. (Right-click on a node also starts an edge.)
  • Del — delete the selected element (own nodes / mods).
  • F fit graph, Ctrl+Z undo, Ctrl+Shift+Z redo.
  • Dotted-border nodes are canonical (mods edit). Amber-dashed nodes are proposed edits to a canonical.

Edits save to the server over REST. Click Refresh to pull other people's changes.
