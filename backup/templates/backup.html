An unsealed row is a pass that did not finish — usually a deploy restarting the worker mid-walk, which is harmless because only sealed generations are ever served or compared against. A run of them is a pass that keeps dying. One file in {{.RehashDenom}} is re-read every pass regardless of its stat, so the whole corpus is re-verified roughly weekly; that is what catches bit rot and a torn write whose mtime never moved again.
